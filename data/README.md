# Dataset

This project uses the public `loans_full_schema` Lending Club-derived teaching extract from OpenIntro.

Source repository

https://github.com/OpenIntroStat/openintro

Direct source file

https://raw.githubusercontent.com/OpenIntroStat/openintro/main/data/loans_full_schema.rda

The repository includes `loans_full_schema.csv`, converted from the public RDA source for easy notebook execution. It contains 10,000 loan records and should be treated as a modelling prototype, not a production underwriting dataset.
